# Spring Boot Training 
SpringBootの基礎学習および検証を目的としたリポジトリです。 

## 学習方針 
単にコードを動かすだけではなく、
- なぜその設計になるのか 
- なぜその設定で動作するのか 
- SpringBootの基礎構文はどのような役割を持つのか  
を意識しながら学習・検証を行います。 

## 目的
- 最小構成のプロジェクトを作成し、仕組みを理解する
- 動作理由を説明できる状態を目指す
- 偶然動いた状態を許さない

## ディレクトリ構成
```text 
spring-sample/
```

## 学習内容
- SpringBoot 基本文法
- DI(Dependency Injection)
- Bean管理
- Controller
- Service
- Repository
- 設定ファイル(application.yml / application.properties)

## 実行方法
```text 
./mvnw spring-boot:run
```

## 開発環境
- OS : Linux(Ubuntu 24.04 LTS)
- 言語 : Java 17
- フレームワーク : SpringBoot 3.5.6
- ビルドツール : Apache Maven 3.8.7
- スクリプト : Shell Script (Bash)
- バージョン管理 : Git / GitHub
- 開発ツール : VS Code
